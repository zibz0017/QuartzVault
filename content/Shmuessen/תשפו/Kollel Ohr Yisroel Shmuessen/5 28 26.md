# <span style="color:rgb(255, 0, 0)">Need source</span>
<span style="display: block; text-align: justify;">By a סוטה, the accused woman needs to bring a קרבן מנחה that does not contain לבונה.
The is because the אמהות are described as "לבונה". We are implying to her that she did not act as the אמהות did.</span>
# Shmuess
## Question
<span style="display: block; text-align: justify;">This woman did *far* worse than not act like the אמהות. It seems like an odd description of what she did.
Almost nobody acts with the greatness of the אמהות.</span>
## Answer
<span style="display: block; text-align: justify;">The פשט is that this woman didn't act with proper aspiration to be like the אמהות. If this person did, this woman would have not done this עבירה.</span>
