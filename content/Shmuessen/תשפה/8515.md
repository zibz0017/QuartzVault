# &lrm;רבינו יונה הקדמה לפרשת מצורע
<span style="display: block; text-align: justify;">If a person likes to talk, he should talk a lot. The person just has to make sure to use one's talking for positive purposes, like davening and learning.[^1]</span>
# Shmuess
## Question
<span style="display: block; text-align: justify;">There are many maamarei חז"ל that talk about how one great silence is and how bad speaking excessively is. Why would Shlomo המלך encourage people to talk excessively?</span>
## Answer
<span style="display: block; text-align: justify;">It seems that there are certain traits that people have which are extremely deep part of their nature. Colloquially, we refer to these as personality.</span>
<span style="display: block; text-align: justify;">It isn't feasible to squelch these traits. This is different than מדות, which we do say that one should try to work on their negative מדות. These traits are so much a part of the person that they can't be changed significantly in a healthy way. As such, the proper path one should take is to try to use these traits as best as the person can.</span>
<span style="display: block; text-align: justify;">Obviously, a person should try to limit these traits as much as is feasible, but as we are saying, there is only going to be so much that a person can do.</span>
