## Liquids Mixed together (לח בלח)
### מין במינו
1. <span style="display: block; text-align: justify;">מדאוריתא, one would only require רוב. &lrm;מדרבנן, one would require ששים.&lrm;[^3]</span>
### מין בשאינו מינו
1. <span style="display: block; text-align: justify;">One would require ששים, &lrm;מדאוריתא.&lrm;[^2]</span>
# איסורי דרבנן
1. <span style="display: block; text-align: justify;">In a case of מין בשאינו מינו, לח בלח, one would require ששים. Otherwise, one would only require רוב.&lrm;[^4]</span>

# Basic Reasoning for when there is an איסור דרבנן
1. <span style="display: block; text-align: justify;">The basic idea is that the רבנן require ששים in a case that is "one step removed" from an איסור דאוריתא. As such, in a case of מין בשאינו מינו, where the אסור piece is אסור דאוריתא, even though it is יבש ביבש (which would be בטל ברוב מדאוריתא) the רבנן require ששים because if it was לח בלח, it would require ששים מדאוריתא. This is "one step removed".
   Similarly, in a case of לח בלח, even though it is מין במינו (which would be בטל ברוב מדאוריתא) the רבנן require ששים here, as well, because if it was מין בשאינו מינו, it would require ששים מדאוריתא.
   Furthermore, in cases where the אסור piece only carries an איסור דרבנן, where it is a case of מין בשאינו מינו לח בלח, it is only one step removed from requiring ששים דאוריתא (if the piece of איסור carried an איסור דאוריתא) the רבנן required ששים.
   If it is any other case (either יבש ביבש of מין במינו) it would be "two steps removed" from requiring ששים מדאוריתא. As such, the רבנן did not require ששים in this case.[^5]</span>
## Specific Cases
1. <span style="display: block; text-align: justify;">Granulated foods, such as flour, count as liquids. If אסור and מותר granulated foods are mixed together, we view this as a לח בלח mixture.[^6]
   The reasoning, presumably, is that one uses many grains at once. One doesn't use individual grains. In any spoonful, one will have a mixture of איסור and התר. This is nearly identical to a case of לח בלח.</span>
2. <span style="display: block; text-align: justify;">Individual foods, even if they are wet, such as individual drinks, count as individual things. If individual אסור and מותר liquids are mixed together, we view this as a יבש ביבש mixture.[^7]</span>
3. <span style="display: block; text-align: justify;">For individual foods within one pot, see [[Individual Foods in One Pot|here]].</span>
4. <span style="display: block; text-align: justify;">Even if two of the foods are smaller than the other one (in which case the largest one may be the אסור one), we still say that there is בטל.</span>
## &lrm;איסורי הנאה
1. <span style="display: block; text-align: justify;">מחבר: This is never מבוטל.&lrm;[^8]</span>
2. <span style="display: block; text-align: justify;">יש אומרים: No different than any other case.[^8]</span>
