# &lrm;איסור Is Still there
## Mostly התר
1. <span style="display: block; text-align: justify;">If a mixture is mostly התר even if the איסור only has a bit of a bad taste it still is considered נותן טעם לפגם and doesn't אסור the mixture.</span>
2. <span style="display: block; text-align: justify;">Some are מחמיר and say that we only say that this is considered to be נותן טעם לפגם if it makes the food inedible. This is because even if the איסור tastes a little bad, the person is gaining by having the איסור here because now there is more food.</span>
3. <span style="display: block; text-align: justify;">We פסקען like the first שיטה.</span>
4. <span style="display: block; text-align: justify;">However. if it gives off no taste at all (neither good nor bad), it does not count as נותן טעם לפגם and so the food would be אסור (unless there is 60x the איסור).</span>
## Half and Half (or Mostly איסור)
1. <span style="display: block; text-align: justify;">There is a מחלוקת if the איסור needs to be a totally bad taste that makes it inedible or even if it is only a little bad if that is enough (just like where the mixture is mostly התר).</span>
2. <span style="display: block; text-align: justify;">We פסקען that the mixture needs to be inedible.</span>
# &lrm;איסור Is Removed
1. <span style="display: block; text-align: justify;">If the איסור is removed or it melts, the food is מותר, even if it is רוב איסור and even if the איסור only had a bit of a bad taste. The same is true if the איסור had no taste at all.</span>
2. <span style="display: block; text-align: justify;">However, if the איסור melts into the התר, we still view this as the physical איסור itself. One would need more התר than איסור for this to be מותר.&lrm;[^1]</span>
# Brine as Part of the Ratio
1. <span style="display: block; text-align: justify;">Brine from איסור counts as איסור in terms of the ratio. As such, if there is brine here, that can make the ratio half and half (or mostly איסור).</span>
