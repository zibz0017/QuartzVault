# Mostly התר
## שיטות
1. If a mixture is mostly התר or the איסור was removed and there are only בליעות of איסור left, then even if the איסור only has a bit of a bad taste it still is considered נותן טעם לפגם and doesn't אסור the mixture.
2. Some are מחמיר and say that even if the איסור tastes bad, there is some gain by having the איסור here because now there is more food. As such, the איסור can be מבוטל only if it tastes as bad enough to make the food inedible.
## How We פסקען
1. We פסקען like the first שיטה.
2. However, if the איסור was not removed, if it gives off no taste at all (neither good nor bad), it does not count as נותן טעם לפגם.
# Half and Half (or Mostly איסור)
## שיטות
1. There is a מחלוקת if the איסור needs to be a totally bad taste that makes it inedible or even if it is only a little bad if that is enough (just like where the mixture is mostly התר).
## How We פסקען
1. We פסקען that the mixture needs to be inedible.
# Brine as Part of the Ratio
1. Brine from איסור counts as איסור in terms of the ratio. As such, if there is brine here, that can make the ratio half and half (or mostly איסור).
