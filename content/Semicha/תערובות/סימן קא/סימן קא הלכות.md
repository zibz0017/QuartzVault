# &lrm;חתיכה הראויה להתכבד
## &lrm;בטל By חתיכה הראויה להתכבד
1. <span style="display: block; text-align: justify;">מדרבנן, a חתיכה הראויה להתכבד is [[סימן ק הלכות#&lrm;בטל by בריה|like a בריה]] in the sense that it is not מבוטל in any amount. If it is אסור בהנה, it makes the mixture it falls into אסור בהנה.&lrm;[^1]
   (Even though the חתיכה הראויה להתכבד is אסור בהנה, and therefore, technically, not something respectable, the bar for whether it is a חתיכה הראויה להתכבד or not is dependent on what it would be, לו יצור it was מותר.&lrm;[^2])</span>
2. <span style="display: block; text-align: justify;">These הלכות are the same whether the food is אסור דרבנן or דאורייתא.&lrm;[^3] <span style="color:rgb(255, 0, 0)">Presumably, this is true about all things that are not מבוטל. It clearly is true about דבר שיש לו מתירין (see ט"ז ס"ק ג here). I assume it is true all of things. I really would like to make a file about all of the rules that everything has in common</span></span>
3. <span style="display: block; text-align: justify;">For discussion about מין במינו vs מין בשאינו מינו, see [[מין במינו Versus מין בשאינו מינו|here]].</span>
## &lrm;ספק חתיכה הראויה להתכבד
1. <span style="display: block; text-align: justify;">If there is a ספק if the food is a חתיכה הראויה להתכבד, it can be מבוטל, [[סימן ק הלכות#&lrm;ספק if there is a בריה|just like by בריה]] (since this is מדרבנן). This even includes a case where we know exactly what fell in but we just have a ספק if that is considered ראויה להתכבד in this location (as ראויה להתכבד is dependent upon that, as discussed [[#What is Considered ראויה להתכבד|below]]).&lrm;[^4]</span>
2. <span style="display: block; text-align: justify;">However, if one knows that the food that fell in is a חתיכה הראויה להתכבד but he doesn't know if it is אסור, it can not be מבוטל.&lrm;[^5]</span>
## Requirements for חתיכה הראויה להתכבד
### Not a חתיכה הראויה להתכבד in Its Present State
1. <span style="display: block; text-align: justify;">If something is missing some steps in its preparation, there is discussion about whether it can count as a חתיכה הראויה להתכבד. For more details, see [[Something Missing Steps in its Preparation Regarding חתיכה הראויה להתכבד|here]].</span>
2. <span style="display: block; text-align: justify;">Even if the preparations for the אסור food were completed after it has been מבוטל (and so should now become a חתיכה הראויה להתכבד and no longer מבוטל), we do not say חוזר וניעור and so it remains מבוטל.&lrm;[^6]</span> ^c6558d
3. <span style="display: block; text-align: justify;">(If something started out as a חתיכה הראויה להתכבד and then became not חתיכה הראויה להתכבד after it was already mixed in, it actually loses its status as a חתיכה הראויה להתכבד and can be מבוטל. For more details, see [[Additional Details about Requirements for חתיכה הראויה להתכבד#Ground up after it Fell in|here]].)</span>
4. <span style="display: block; text-align: justify;">(According to the רמ"א, we only say these הלכות about a חתיכה הראויה להתכבד. A דבר שבמנין, however, would still retain its status as a דבר שבמנין and would not be מבוטל.
   Most פוסקים disagree with this.[^7]) <span style="color:rgb(255, 0, 0)">Need to add link to סימן קי.</span></span>
### איסור בלוע
1. <span style="display: block; text-align: justify;">The food must itself be אסור, not that it has absorbed אסור בליעות. This is because we are only concerned about the איסור and בליעות are not  ראויה להתכבד.&lrm;[^8] For a discussion about בב״ח, see [[Additional Details about Requirements for חתיכה הראויה להתכבד#&lrm;בב״ח|here]]. For a discussion about meat that hasn't been salted, see [[Meat that has not been Salted Regarding חתיכה הראויה להתכבד|here]].</span> ^c44783
### Small Amounts
1. <span style="display: block; text-align: justify;">There is a מחלוקת about something that is ראויה להתכבד but only eaten when it is cut into relatively small pieces. For more details, see [[Additional Details about Requirements for חתיכה הראויה להתכבד#Something Normally Served as Small Pieces|here]].</span>
2. <span style="display: block; text-align: justify;">Something which is not usually served in a small amount is not considered a חתיכה הראויה להתכבד if only a small amount falls in.[^9] (For example, a steak is not going to be served in a one ounce portion. As such, this would not be considered to be a חתיכה הראויה להתכבד.)</span>
3. <span style="display: block; text-align: justify;">Similarly, the קליפה of a חתיכה הראויה להתכבד that becomes אסור will not be considered a חתיכה הראויה להתכבד because it is too small (besides for the fact that, usually, this will be a an איסור בלוע, except regarding בב״ח).[^10]
   However, if the קליפה is removed and then goes into the food, it is considered a חתיכה הראויה להתכבד (obviously assuming that the חתיכה is something that is ראויה להתכבד).&lrm;[^11]</span>
### Ground up
1. <span style="display: block; text-align: justify;">For discussion about a חתיכה הראויה להתכבד that is ground up or cut into tiny pieces, see [[Additional Details about Requirements for חתיכה הראויה להתכבד#Something Ground up|here]].</span>
### Some of it Was Removed
1. <span style="display: block; text-align: justify;">There is a מחלוקת about a חתיכה הראויה להתכבד that had some of it removed and is now less חשוב. For more details, see [[Additional Details about Requirements for חתיכה הראויה להתכבד#Missing Some of it|here]].</span>
## What is Considered ראויה להתכבד
1. <span style="display: block; text-align: justify;">ראויה להתכבד is subjective to the time and place.[^12]</span>
