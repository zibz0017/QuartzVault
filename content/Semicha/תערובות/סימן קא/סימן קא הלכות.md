# &lrm;חתיכה הראויה להתכבד
## &lrm;בטל by חתיכה הראויה להתכבד
1. <span style="display: block; text-align: justify;">מדרבנן, a חתיכה הראויה להתכבד is [[סימן ק הלכות#&lrm;בטל by בריה|like a בריה]] in the sense that it is not מבוטל in any amount. If it is אסור בהנה, it makes the mixture it falls into אסור בהנה.&lrm;[^1]</span>
   (Even though the חתיכה הראויה להתכבד is אסור בהנה, and therefore, technically, not something is respectable, the bar for whether it is a חתיכה הראויה להתכבד or not is dependent on what it would be, לו יצור it was מותר.&lrm;[^2])
2. <span style="display: block; text-align: justify;">These הלכות are the same whether the food is אסור דרבנן or דאורייתא.&lrm;[^3]</span>
3. <span style="display: block; text-align: justify;">For discussion about מין במינו vs מין בשאינו מינו, see [[מין במינו Versus מין בשאינו מינו|here]].</span>
### &lrm;ספק חתיכה הראויה להתכבד
1. <span style="display: block; text-align: justify;">If there is a ספק if the food is a חתיכה הראויה להתכבד, it can be מבוטל, [[סימן ק הלכות#&lrm;ספק if there is a בריה|just like by בריה]] (since this is מדרבנן). This even includes a case where we know exactly what fell in but we just have a ספק if that is considered ראויה להתכבד in this location (as ראויה להתכבד is dependent upon that, as discussed [[#What is Considered ראויה להתכבד|below]]).&lrm;[^4]</span>
2. <span style="display: block; text-align: justify;">However, if one knows that the food that fell in is a חתיכה הראויה להתכבד but he doesn't know if it is אסור, it can not be מבוטל.&lrm;[^5]</span>
### Not a חתיכה הראויה להתכבד in Its Present State
1. <span style="display: block; text-align: justify;">If something is missing some steps in its preparation, there is discussion about whether it can count as a חתיכה הראויה להתכבד. For more details, see [[Something Missing Steps in its Preparation Regarding חתיכה הראויה להתכבד|here]].</span>
## Requirements for חתיכה הראויה להתכבד
1. <span style="display: block; text-align: justify;">The food must itself be אסור, not that it has absorbed אסור בליעות. This is because we are only concerned about the איסור and בליעות are not  ראויה להתכבד.&lrm;[^6] For a discussion about בב״ח, see [[Details about Requirements for חתיכה הראויה להתכבד#&lrm;בב״ח|here]].</span> ^c44783
2. <span style="display: block; text-align: justify;">There is a מחלוקת about something that is ראויה להתכבד but only eaten when it is cut into relatively small pieces. For more details, see [[Details about Requirements for חתיכה הראויה להתכבד#Something Cut up into Small Pieces|here]].</span>
3. <span style="display: block; text-align: justify;">For discussion about a חתיכה הראויה להתכבד that is ground up or cut into tiny pieces, see [[Details about Requirements for חתיכה הראויה להתכבד#Something Ground up|here]].</span>
4. <span style="display: block; text-align: justify;">There is a מחלוקת about a חתיכה הראויה להתכבד that had some of it removed and is now les חשוב. For more details, see [[Details about Requirements for חתיכה הראויה להתכבד#Missing Some of it|here]].</span>
### What is Considered ראויה להתכבד
1. <span style="display: block; text-align: justify;">ראויה להתכבד is subjective to the time and place.[^7]</span>
## Specific Examples
1. <span style="display: block; text-align: justify;">Unsalted meat is not considered to be a חתיכה הראויה להתכבד because the meat is technically fine and the whole issue is the blood inside of it. This is an איסור בלוע and so it is not a חתיכה הראויה להתכבד.&lrm;[^8] (The רמ"א is clearly assuming that the blood itself is not considered to be a חתיכה הראויה להתכבד.)</span>
2. <span style="display: block; text-align: justify;">Food that is אסור כדי קליפה (for example, by בב״ח) can't be aחתיכה הראויה להתכבד.&lrm;[^9]</span>
   However, if the קליפה is removed and then goes into the food, it is considered a חתיכה הראויה להתכבד (obviously assuming that the חתיכה is something that is ראויה להתכבד).&lrm;[^10]
