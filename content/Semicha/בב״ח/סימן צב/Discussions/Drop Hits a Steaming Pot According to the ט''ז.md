# הלכה
1. According to the ט"ז, if a drop hits the outside of a covered pot filled with steam, if we are dealing with potential איסור דאורייתא (for example, a drop of milk hits a pot of meat), we treat it with the חומרות of both hitting above and below.
2. If it is only a potential איסור דרבנן (for example, a drop of milk hits a pot of chicken), we treat it as if it hit above the food.
# Reason
1. The steam counts as a connection between where the drop hit and the food. As such, we need to treat it like it hit below the food.
2. However, the steam is constantly shifting. As such, there may be a moment when the steam will not be linking the spot where the drop hit to the food.
3. If we are talking about an איסור דאורייתא, we have to be מחמיר like it is not connected (and like it is connected). If it is an איסור דרבנן, then we can be מקל because of ספק דרבנן להקל and assume that it was always connected.
