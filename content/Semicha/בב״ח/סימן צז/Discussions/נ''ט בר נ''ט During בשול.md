# Basic case
1. There is a מחלוקת about what happens if there is a נ"ט בר נ"ט situation while the food is cooking.
   For example, if there is a leak of dairy/meat onto the oven floor (while the oven is on), if we say that the בליעות spread through the floor, then it can spread to another food that is on the floor as well. What is the הלכה regarding this second food?
# שיטות
1. חוות דעת, ש"ך (לפי פתחי תשובה), ט"ז (לפי פתחי תשובה): Since this is actually on the flame, we don't view this as נ"ט בר נ"ט. We only view this as one נ"ט.
2. בית אפרים: This maintains the standard דין of נ"ט בר נ"ט.
