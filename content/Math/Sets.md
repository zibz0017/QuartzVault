# Definition
<span style="display: block; text-align: justify;">A set is a collection of any objects. Objects are only listed once (meaning, an object is not repeated. A set does not contain the same object more than once.) In math, it usually is just a collection of numbers. For example:</span>
$$A=\{1,4,17,-2.67\}$$
<span style="display: block; text-align: justify;">This means set $A$ contains the values, 1, 4, 17, and -2.67.</span>
# Operations
## Intersection
<span style="display: block; text-align: justify;">Create a new set which contains all of the values which are shared by two other sets. The symbol for intersection is $\cap$.</span>
<span style="display: block; text-align: justify;">A way to think about it is like the word "and". We are asking what is in this set *and* that set.</span>
### Example
$$A=\{1,4,23,46,2\}$$
$$B=\{6,1,1078,-248,4\}$$
<span style="display: block; text-align: justify;">The intersection contains the values that are in both set $A$ and set $B$. As such:</span>
$$A\cap{B}=\{1,4\}$$
## Union
<span style="display: block; text-align: justify;">Creates a new set which contains all of the values which are in either of the two sets. The symbol for union is $\cup$.</span>
<span style="display: block; text-align: justify;">A way to think about it is like the word "or". We are asking what is in either this set *or* in that set.</span>
### Example
$$A=\{1,4,23,46,2\}$$
$$B=\{6,1,1078,-248,4\}$$
<span style="display: block; text-align: justify;">The union contains the values that are in either set $A$ or set $B$. As such:</span>
$$A\cup{B}=\{1,4,23,46,2,6,1078,-248\}$$
<span style="display: block; text-align: justify;">Remember that sets only contain one of every value. There are not repeats. As such, and repeated numbers (like 1 and 4) are only put into the new set once.</span>
## Subtracting Sets (or Relative Complement)
<span style="display: block; text-align: justify;">We can "subtract" one set from another, meaning, we create a new set only with values which are in the first set but not the second set. The symbol for this is $\setminus$ or just a minus sign ($-$).</span>
### Example
$$A=\{1,4,23,46,2\}$$
$$B=\{6,1,1078,-248,4\}$$
<span style="display: block; text-align: justify;">Set $A$ minus set $B$ (or the relative complement of set $B$ in set $A$) is:</span>
$$A\setminus{B}=\{23,46,2\}$$
<span style="display: block; text-align: justify;">This can also be written as:</span>
$$A-B=\{23,46,2\}$$
<span style="display: block; text-align: justify;">These are all of the values which are in set $A$ and not in set $B$.</span>
<span style="display: block; text-align: justify;">We can also go the other way:</span>
$$B\setminus{A}=\{6,1078,-248\}$$
<span style="display: block; text-align: justify;">Or:</span>

$$B\setminus{A}=\{6,1078,-248\}$$$$B-A=\{6,1078,-248\}$$
<span style="display: block; text-align: justify;">These are all of the values which are in set $B$ and not in set $A$.</span>
# Types of Sets
## Universal Set
<span style="display: block; text-align: justify;">Contains all objects in the universe. For the most part, we are referring to a certain type of object. For example, we may have the universal set of all integers, or the universal set for all rational numbers. The symbol for a universal set is $\cup$ (the as the symbol for [[#Union|union]]). You would then need to specify which "universe" you are talking about (all real numbers, all rational numbers, etc.)</span>
### Particular Examples of Universal Sets
<span style="display: block; text-align: justify;">The set of all integers is: $\mathbb{Z}$.</span>
<span style="display: block; text-align: justify;">The set of all rational numbers is: $\mathbb{Q}$.</span>
<span style="display: block; text-align: justify;">The set of all real numbers is: $\mathbb{R}$.</span>
## Null Set or Empty Set
<span style="display: block; text-align: justify;">This is a set which contains no values. The symbol for this is: $\{\}$ or $\emptyset$.</span>
